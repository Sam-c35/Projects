# Projet Python

Petits projets Python réalisés pour s'amuser en traitement de données sur des sujets qui m'intéressent et pour réaliser des simulations sur le même thème.
C'est aussi une occasion pour moi d'apprendre à utiliser Git. 

## Fonctionnalités

Pour le moment, deux programmes distincts : 
- Un pipeline de traitement permettant d'analyser des données de consommation électrique d'un échantillon de maisons en France
- Un second script dédié à faire des simuations "en bazarre" permettant de tester des modèles, les comparer... et s'amuser !
